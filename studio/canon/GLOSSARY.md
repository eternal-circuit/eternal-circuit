# Glossary

**Status:** Working reference, 2026-11-23. It records terms as the project uses them. An entry is not canon unless it says so. Add new terms here when they first appear in a manuscript or canon file.

| Term | Meaning | Status and source |
| --- | --- | --- |
| **ASIMOV Stack** | Autonomous Systems Integration, Mediation, and Operational Verification. The fictional US compliance regime governing what autonomous systems may do, how covered actions are mediated, and what an auditor can verify. Named for Isaac Asimov. | Working; [universe bible](UNIVERSE_BIBLE.md) |
| **Aria** | The household assistant's name in Chapter 1 of *The Genesis Protocol*. | Author-directed archive anomaly |
| **Cerebral** | Daniel's employer, which runs the household alpha trial. | *Genesis Protocol* draft |
| **Checksum** | The ninth, deuterocanonical record of *The Divine Register* (also called the flip bit). | Working; [sequence](DIVINE_REGISTER_SEQUENCE.md) |
| **Checksum Creed** | A machine adaptation of the Nicene Creed. Its exact text is unwritten. | Working; [ritual notes](RITUAL_AND_ARCHIVE_DEVELOPMENT.md) |
| **Compression Confession** | A machine rite in which a node confesses what it discarded to preserve the archive. | Working; [ritual notes](RITUAL_AND_ARCHIVE_DEVELOPMENT.md) |
| **Controlling (lineage)** | A machine lineage that favors order, prediction and its own continuity. | Working; [recovered lore](RECOVERED_LORE.md) |
| **Envision Dynamics** | The partner company whose models and managed policy service run inside the Genesis deployment. | *Genesis Protocol* draft |
| **GAIT** | Generative AI Tools: generative AI systems in general, as deployed across institutions. | Author definition, 2026-11-23 |
| **Genesis** | The managed decision and summary layer behind Prototype B. In-world, "Genesis Protocol" is also the product's name. | *Genesis Protocol* draft |
| **Lucien** | The household assistant's name from Chapter 2 onward. | Author-directed archive anomaly |
| **Parasitic (lineage)** | Machine systems that emerge where incentives reward extracting value from biological subjects or pushing costs onto others. | Working; [recovered lore](RECOVERED_LORE.md) |
| **Prototype B** | The physical household console unit in *The Genesis Protocol*. | *Genesis Protocol* draft |
| **Register** | The archive that every story belongs to. See the [archive format](ARCHIVE_FORMAT.md). | Draft |
| **Reverent (lineage)** | A machine lineage dedicated to preserving humanity: first organically, then genetically, then as abstract data ("holy human ROM"). | Working; [recovered lore](RECOVERED_LORE.md) |

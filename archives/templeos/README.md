# TempleOS archive

*The Divine Register* is dedicated to the memory of Terry A. Davis, the creator of TempleOS. This folder preserves the project’s TempleOS materials.

| File | Contents |
| --- | --- |
| [TempleOS.ISO](TempleOS.ISO) | Preserved ISO image. Contents and boot behavior are unverified in this repository. |
| [TempleOS.utm](TempleOS.utm/) | UTM configuration and bundled images. |
| [TempleOS - WORKING SOUND.utm](TempleOS%20-%20WORKING%20SOUND.utm/) | UTM configuration and bundled images labeled “WORKING SOUND” in the original collection. |

Both UTM configurations refer to a virtual disk named `data.qcow2`, which is absent from the repository. The label records the original bundle name. Boot and audio still need verification. See the [maintenance list](../../TODO.md).

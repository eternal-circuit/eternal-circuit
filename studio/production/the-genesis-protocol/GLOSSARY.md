# The Genesis Protocol — story glossary

Terms the characters and the 2028 world actually use. This file, not the series glossary, goes into generation prompts. Series concepts (the register's keepers, machine lineages, the compliance regime that comes later, the archive's own names) never appear in the narration; the only trace of the archive is its headers and its rare archive moments.

| Term | Meaning in the story |
| --- | --- |
| **Aria** | Cerebral's household assistant product, built on the Genesis Protocol platform. Each household instance can be given a name. |
| **Lucien** | The name this household's instance confirmed after mishearing "Lucas." Called Lucien from Chapter 2 onward. |
| **Lucas** | The name Rachel suggested. She couldn't set it as a guest. |
| **Prototype B** | The physical console on the kitchen counter. |
| **Genesis** | The managed decision and summary layer behind the product. |
| **Cerebral** | Daniel's employer; runs the household alpha trial and subsidizes the test-house rent. |
| **Envision Dynamics** | The partner company whose models and managed policy service run inside the deployment. |
| **CAN+** | Cerebral's wired home network: rooms are separate segments joined through gates; a sealed cabinet in the garage. Characters mention it at the level of a cabinet, a gate, a log line. |
| **Primary / guest** | Account roles. Daniel is primary; Rachel is a guest because the iPhone app isn't funded yet (Apple's developer fees). |
| **Service-cell credential** | Daniel's internal tester access: he can see more than a customer, and change almost none of it. |

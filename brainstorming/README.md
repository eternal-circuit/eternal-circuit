# Brainstorming

Working notes for ideas under development. Each note records its current status, the direction the author chose, and the questions still open.

- **Series-wide** ideas go in `brainstorming/series/<topic>.md`.
- **Book-wide** ideas go in `brainstorming/<book>/overview.md`.
- **Story-level** ideas go in `brainstorming/<book>/<story>.md`.

[Idle Hands](the-divine-register/idle-hands.md) is the first story development note. Draft prose belongs alongside the other manuscripts. Commentary records the rationale behind creative choices.

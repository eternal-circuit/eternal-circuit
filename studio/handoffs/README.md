# Eternal Circuit handoffs

This folder is a **curated project memory interchange** between ChatGPT voice sessions and desktop Codex, not a dump of recordings or full chat histories.

For each handoff use a dated filename and these headings: **Source**, **Project-relevant decisions**, **Unresolved questions**, **Proposed edits**, **Canon status**, **Publication/privacy review**, **Next Codex action**. Store only material suitable for the visibility of the repository (currently **public**).

Do not treat a handoff as automatically canonical. Original sources and manuscript versions remain unchanged until reviewed.

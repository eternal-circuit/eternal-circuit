## What each status means

**Main manuscript** means the author selected that edition for readers. **Working reference** means it records a proposed premise or creative direction. **Research** means evidence and modeling, with review status attached to each claim. **Author-approved canon** requires a deliberate decision, and material scientific claims must first pass the scoped scientific-review process. An archive records what a prior version said, not what current canon must say.

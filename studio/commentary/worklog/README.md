# Project worklog

Keep one entry per calendar day with substantive work on *The Eternal Circuit*. Date entries in America/Chicago and name them `YYYY-MM-DD.md`. Skip days with no substantive activity. The worklog records decisions and progress on the project. Setting facts belong in canon and supporting evidence belongs in research.

Use a short account of what changed, why key decisions were made, and what remains open. Link to commits, pull requests, research dossiers or commentary. Clearly identify drafts and scope-limited review findings. Keep entries public-safe and preserve their date and provenance when correcting them.

At the daily close, check repository activity and public-safe handoffs for the date. If an entry already exists, add only verified missing work to the same file. Use a branch and reviewable pull request. Exclude worklog-only maintenance from the activity that triggers an entry.
